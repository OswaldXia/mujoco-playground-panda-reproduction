# 01C｜正运动学、雅可比与逆运动学

建议 90–120 分钟。前置：01B。

## 从关节到末端

串联机械臂每个关节贡献一个局部变换。给定关节位置
`q=[q1,...,q7]`，沿链相乘得到末端姿态：

$$
T_{world,tip}(q)=T_0^1(q_1)T_1^2(q_2)\cdots T_6^{tip}(q_7).
$$

这是正运动学（FK）：输入关节，输出末端。通常确定且快速。

## 从末端目标回到关节

逆运动学（IK）输入目标末端姿态，寻找一个 `q*` 使 FK 接近目标。它可能：

- 有多个解：肘部可以向上或向下；
- 无解：目标超出工作空间或要求不可能姿态；
- 接近奇异位形：很小的末端变化需要很大的关节变化；
- 需要选择离当前姿态近、且不碰撞的解。

局部关系由雅可比给出：`delta_x ≈ J(q) @ delta_q`。数值 IK 常迭代求一个
`delta_q` 来缩小位姿误差，并加入关节限位、阻尼或正则项。不要把 IK 理解为一
个总能返回正确答案的黑盒。

## 运动学不是动力学

FK/IK 讨论几何关系；动力学还包含速度、加速度、质量、力矩、重力和接触。
IK 给出的关节目标仍需执行器与物理仿真推进才能产生运动。抓到方块尤其依赖接触
摩擦，不能只靠 IK 判断成功。

## Panda 中的一步

本环境从当前 tip position 加一个笛卡尔增量，裁剪到工作空间，再调用
`compute_franka_ik`。若 solver 无解，环境不会把非法结果交给执行器，而是保留
旧控制并记录 `no_soln` 信号。这意味着轨迹停住可能来自：策略几乎不动、工作区
裁剪，或 IK 无解；三者不能仅凭视频区分。

## 暂停并预测

1. 只给目标位置而不约束姿态，IK 解通常会更多还是更少？
2. tip 已在工作空间边界，策略继续朝外给动作，真实增量会怎样？
3. IK 有解是否保证方块被稳定抓住？

答案：更多；被裁剪，可能近似为零；不保证，接触与动力学仍未解决。
