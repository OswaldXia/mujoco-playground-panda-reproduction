# Panda 视觉强化学习：从原理到可复现实验

> 课程版本：v0.9.1（易学性改进版）
> 对应代码基线：上游 `4db186a5`，本课程分支
> `docs/course-v0.9.1-usability`
> 预计投入：90–110 小时，建议 8–12 周

这不是一份“照抄命令即可完成”的安装说明，而是一条从机器人与强化学习
概念、仿真环境源码、GPU 训练，到独立评估和受控改进的完整学习路径。最终
目标是让学习者能独立解释、复现、诊断并改进本仓库中的
`PandaPickCubeCartesian`，而不是声称掌握全部机器人学或强化学习。

快速执行请继续使用 [`reproduction/README.md`](../../reproduction/README.md)；
本课程解释每一步为什么存在、如何验证、失败后如何定位。

第一次使用请先打开 **[`START_HERE.md`](START_HERE.md)**，运行零依赖预检并选择
Mac 基础、离线分析或 Linux GPU 路线。

## 开始前应已掌握

- Python 基本语法、函数、类、NumPy 数组；
- 终端、路径、环境变量、`venv`/`pip`；
- Git 分支、提交、合并的基本操作；
- 能阅读 JSON/CSV，并能运行一个 Python 脚本。

不要求预先了解强化学习、机器人运动学、MuJoCo、JAX、Brax 或 CUDA。若上述
四项仍不熟悉，应先补齐通用开发基础；本课程不再设置该阶段。

## 学完后应该能做什么

1. 用坐标系、状态、动作、奖励和终止条件解释抓取任务；
2. 从 MJCF、环境类、PPO 配置追踪一条完整的数据流；
3. 在 Mac 上验证环境，在 Linux NVIDIA GPU 上训练和评估；
4. 判断训练是否真正收敛，而不是只看单个视频或平均奖励；
5. 设计固定种子、置信区间、分层评估和轨迹级失败分类；
6. 识别评估泄漏，并用一次只改变一个变量的实验改进策略；
7. 用代码、证据、实验记录和明确边界向面试官讲清项目。

## 五道能力门

- **Gate 1：理论/环境。** 通过第 02 章自测，并能从 reset 到 reward 手画数据流。
- **Gate 2：计算栈。** 能解释 `jit` 首次编译、`vmap` 批处理和显存随并行度变化。
- **Gate 3：复现。** Mac smoke 与 Linux GPU smoke 均有机器可读证据。
- **Gate 4：评估。** 能独立恢复 checkpoint，并按固定协议复现统计结论。
- **Gate 5：毕业实验。** 预注册、单变量、含回归测试，并如实接受失败结果。

每道 Gate 的证据必须进入自己的学习分支；没有产物或无法口头解释，就先回到
对应章节，不继续消耗 GPU。READY/PRACTICED/PILOT 的客观区别见
[`GATE_RUBRIC.md`](GATE_RUBRIC.md)；离线练习通过不等于正式 checkpoint 已复现。

## 推荐节奏

- 每周 8–12 小时：理论 30%，源码阅读 25%，动手 35%，复盘 10%。
- 第 00–06 章主要在 Mac 完成；第 07 章以后按需使用 Linux NVIDIA 服务器。
- 每次实验先写预测，再运行；先定义验收线，再查看结果。
- `reproduction/artifacts/` 保存本机大文件，Git 只保存代码、小型结果与说明。

## 使用方法

1. 从 [`START_HERE.md`](START_HERE.md) 运行预检并确认路线。
2. 新建学习分支：`git switch -c learn/panda-course`。
3. 若当前 checkout 没有 `.venv`，先执行第 06 章“操作”中的创建与安装命令，
   安装完成后返回第 00 章；Mac/Linux 必须各自在本机创建。
4. 顺序完成章节，不跳过 Gate；把答案写入自己的 `notes/`。
5. 运行相应 lab，并保存小型输出；不要提交 `.venv`、checkpoint 或视频。
6. 对照 [`exercises/`](../exercises/README.md) 自测，再查看
   [`solutions/`](../solutions/README.md)。
7. 遇到问题先查 [`troubleshooting.md`](../reference/troubleshooting.md)。
